Sudan Drive — مشروع جامعي تجريبي لمادة التجارة الإلكترونية

الملفات:
- index.html: صفحات ومحتوى الموقع.
- style.css: التصميم المتجاوب.
- script.js: البحث والتصفية والمفضلة ونموذج طلب الحجز.

طريقة النشر على GitHub Pages:
1. افتح مستودع GitHub الذي أنشأته.
2. اختر Add file ثم Upload files.
3. ارفع الملفات الثلاثة (index.html وstyle.css وscript.js) إلى جذر المستودع.
4. اضغط Commit changes.
5. افتح Settings ثم Pages.
6. من Build and deployment اختر Deploy from a branch.
7. اختر main ثم /(root)، واضغط Save.
8. انتظر قليلاً ثم افتح الرابط الذي يظهر في صفحة Pages.
